CSS Transformations Showcase

Hover over any card below to trigger its 2D CSS transformation animation.

🔄

Rotate

transform: rotate(45deg);

Rotates the element 45 degrees clockwise around its center point.

🔍

Scale

transform: scale(1.2);

Enlarges the box size uniformly by 20% on hover.

🚀

Translate

transform: translate(0, -15px);

Shifts the position 15px upwards along the vertical Y-axis.

📐

Skew

transform: skew(-15deg, 5deg);

Distorts the box along the X and Y axes creating a slanted effect.
