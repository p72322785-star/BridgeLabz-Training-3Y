CSS Box Model Exploration

Understanding Content, Padding, Border, and Margin Layers

1. Concentric Box Model Layers

Each layer is visually differentiated with background colors and dashed outlines.

MARGIN (Spacing outside the border)
BORDER (Surrounds padding & content)
PADDING (Internal space around content)
CONTENT (Actual text/media)

2. box-sizing Comparison

Both boxes below have width: 260px, padding: 20px, and border: 8px.

content-box (Default)

Total Rendered Width:

316px (260 + 40 + 16)

Width applies only to content. Padding and border are added onto the specified width.

border-box (Recommended)

Total Rendered Width:

260px (Padding & border included)

Width includes content, padding, and border. The total width never exceeds 260px.
