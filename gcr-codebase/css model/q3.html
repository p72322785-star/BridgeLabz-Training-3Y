Linear Gradient Section

This section features a multi-stop linear gradient background. Linear gradients transition colors smoothly along a straight line (in this case, diagonally at 135deg).

background-attachment: fixed

Notice how the background remains fixed in place as you scroll down to the next section, creating a clean parallax depth effect.

Radial Gradient Section

This section features a circular radial gradient background. Radial gradients radiate outward from a central point, transitioning colors seamlessly in concentric rings.

radial-gradient(circle at center)

The gradient originates at the center of the viewport and spreads outwards towards the outer edges.
