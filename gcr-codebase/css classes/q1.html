CSS Pseudo-Classes Demonstration

:hover

Applies when the cursor hovers over an element. The link background and text color change when hovered.

Hover Over Me

:focus

Applies when an element gains focus (via click or tab key). Click the input box to see its border and background glow green.

:active

Applies while an element is actively being pressed down by mouse click. Press and hold the button to see it turn purple.

:nth-child()

Selects siblings based on their numerical index position. Odd and even list items display alternating background colors.
