Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(100%);

Media Queries

Change styles according to screen size.

@media (max-width: 700px)

Responsive Design

Create websites that work on different devices.

width: 100%;

Typography

Make text flexible for different screen sizes.

font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

Arrange elements in rows or columns.

display: flex;

CSS Grid

Create flexible rows and columns.

display: grid;
